# Paradise-nursery

Paradise Nursery is an online plant shop where customers can browse a variety of beautiful houseplants, view plant details, and add plants to their shopping cart.

## Features

- Browse plants by category
- At least six plants in each category
- Plant images, names, descriptions, and prices
- Add plants to shopping cart
- Dynamic shopping cart count
- Increase and decrease quantities
- Remove products from cart
- Automatically calculate total prices
- Continue shopping functionality
- Checkout placeholder
- Responsive user interface
- Redux state management

## Plant Categories

1. Indoor Plants
2. Succulents
3. Flowering Plants

## Technologies Used

- React
- Redux Toolkit
- React Redux
- React Router
- CSS
- JavaScript
